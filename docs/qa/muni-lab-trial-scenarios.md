# MUNI lab 시운전 시나리오

MUNI lab macOS 앱, Aside 연동, 연구 파이프라인 및 오류 복구 동작에서 결함을 찾기 위한 시운전 절차입니다.

## P0 필수 시나리오

### 1. Spotlight 실행

#### 절차

1. MUNI lab과 Aside를 모두 종료합니다.
2. Spotlight에서 `MUNI lab`을 검색합니다.
3. 앱 아이콘과 이름을 확인합니다.
4. 앱을 실행합니다.

#### 합격 기준

- 검색 결과가 하나만 표시됩니다.
- MUNI lab 아이콘이 표시됩니다.
- Aside가 전면으로 열립니다.
- MUNI lab 탭이 생성되고 첫 화면이 정상 렌더링됩니다.
- 빈 창이나 네이티브 WebKit 창이 별도로 열리지 않습니다.

### 2. 중복 실행

#### 절차

1. MUNI lab이 열린 상태에서 Spotlight로 다시 실행합니다.
2. 같은 작업을 3회 반복합니다.

#### 합격 기준

- 서버 프로세스가 중복 생성되지 않습니다.
- 불필요한 탭이 계속 증가하지 않습니다.
- 기존 MUNI lab 탭이 선택되거나 새 탭 하나만 정상 생성됩니다.

### 3. 기본 연구 화면

#### 절차

1. 새 연구 대화로 진입합니다.
2. Sidebar, 질문 입력창, 추천 질문 및 출처 설정을 확인합니다.
3. 설정 화면으로 이동한 후 연구 화면으로 복귀합니다.

#### 합격 기준

- `Mucha Science`, `Muchanipo`, `demo`, `mock fallback` 문구가 없습니다.
- 모든 사용자 화면이 `MUNI lab`으로 표시됩니다.
- 앱 아이콘이 Sidebar와 브라우저 탭에서 표시됩니다.
- 화면 이동 후 입력 내용이나 상태가 비정상적으로 초기화되지 않습니다.

### 4. 자격 증명 없는 실행

#### 절차

1. API 키를 제거합니다.
2. 연구 질문을 제출합니다.

#### 합격 기준

- 무한 스피너가 발생하지 않습니다.
- 필요한 자격 증명과 연결 방법이 안내됩니다.
- 실패한 턴이 `error` 또는 입력 가능 상태로 종료됩니다.
- 새로운 질문을 다시 제출할 수 있습니다.

### 5. Quick 과학 질문

다음 질문을 제출합니다.

> 최근 5년간 장내 미생물과 우울증 사이의 인과관계를 다룬 연구를 찾아줘. 관찰연구와 임상시험을 구분하고 근거의 강도와 한계를 표로 정리해줘.

#### 합격 기준

- PRD 인터뷰가 표시되지 않습니다.
- 명확화 질문은 0~2개입니다.
- 2021년 이후 외부 학술 자료만 후보가 됩니다.
- 내부 시스템 문서가 근거로 채택되지 않습니다.
- UI에서 `후보 N / 채택 N`이 구분됩니다.
- 최소 3개 근거가 채택됩니다.

### 6. 수정 요청 후 재검색

#### 절차

1. 근거 승인 단계에서 `수정 필요`를 선택합니다.
2. `임상시험 근거를 추가해줘`라고 입력합니다.

#### 합격 기준

- 오류로 종료되지 않습니다.
- 새로운 검색이 실행됩니다.
- 후보 및 채택 수가 갱신됩니다.
- 근거 승인 단계가 다시 열립니다.
- 이전 결과와 새로운 결과가 혼동되지 않습니다.

### 7. 공급자 타임아웃

#### 절차

1. 연구 실행 중 네트워크 또는 공급자 프로세스를 중단합니다.
2. 실행 종료 상태를 관찰합니다.

#### 합격 기준

- 무한 스피너가 발생하지 않습니다.
- 오류 메시지가 표시됩니다.
- 턴이 명확한 `error` 상태로 종료됩니다.
- 새로운 질문을 제출할 수 있습니다.
- 앱을 재실행해도 이전 `running` 상태가 부활하지 않습니다.

### 8. 최종 보고서

#### 절차

1. 모든 승인 단계를 통과합니다.
2. 최종 보고서를 엽니다.

#### 합격 기준

- 실제 보고서 페이지로 이동합니다.
- 관찰연구와 임상시험이 구분된 표가 있습니다.
- 연도, 근거 강도 및 한계가 표시됩니다.
- 거부된 자료가 채택 근거 표에 포함되지 않습니다.
- 주장과 근거의 연결을 확인할 수 있습니다.
- 보고서가 비어 있거나 `done` 이벤트만 표시되지 않습니다.

## P1 안정성 시나리오

### 9. 앱 종료 수명주기

#### 절차

1. Aside의 MUNI lab 탭을 닫습니다.
2. MUNI lab 프로세스를 종료합니다.
3. 닫았던 탭을 새로고침합니다.
4. Spotlight에서 MUNI lab을 다시 실행합니다.

#### 확인 항목

- 종료 후 백그라운드 서버가 남지 않습니다.
- 종료된 탭이 무한 로딩 상태에 머물지 않습니다.
- 재실행 시 새로운 로컬 주소로 정상 연결됩니다.

### 10. 재실행 및 세션 보안

#### 절차

1. API 키를 입력합니다.
2. MUNI lab과 Aside를 종료합니다.
3. MUNI lab을 다시 실행합니다.

#### 합격 기준

- API 키가 디스크에 평문으로 남지 않습니다.
- 이전 연구 기록이 제품 정책에 맞게 복구됩니다.
- 이전 실행 중 상태가 무한 스피너로 표시되지 않습니다.

### 11. 작은 화면

#### 절차

1. Aside 창을 최소 크기까지 축소합니다.
2. Sidebar를 열고 닫습니다.
3. 설정 및 연구 화면을 확인합니다.

#### 합격 기준

- 버튼과 입력창이 잘리지 않습니다.
- 가로 스크롤이 발생하지 않습니다.
- 한국어 문구가 겹치지 않습니다.
- 아이콘과 텍스트가 클릭 가능한 크기를 유지합니다.

## 권장 실행 순서

핵심 결함을 빠르게 찾으려면 다음 순서로 진행합니다.

1. Spotlight 실행
2. 중복 실행
3. 자격 증명 없는 실행
4. Quick 과학 질문
5. 공급자 타임아웃
6. 최종 보고서
