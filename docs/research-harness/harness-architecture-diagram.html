Muchanipo Research Harness Architecture

Stage gate가 adapter를 선택하고, adapter는 product flow를 결정하지 못한다.

Stage Gate

제품 흐름은 하네스가 소유한다. stage_id가 없으면 실행하지 않고, ambiguous 상태는 block으로 둔다.

Adapter Registry

Claude/Codex/Kimi/OpenCode/Grok/Gemini는 역할별 adapter로 제한된다. 자동 fanout은 기본 금지다.

Evidence Layer

raw output, provenance, execution log, state assertion, evidence manifest가 있어야 최종 산출물로 승격된다.
